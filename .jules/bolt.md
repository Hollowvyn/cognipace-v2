## 2024-06-14 - Problem Library Filtering Optimization\n**Learning:** The `createProblemSearchText` function calculates a big search text for each problem row every time we want to filter the table based on the search query. This causes string construction to block the main thread unnecessarily because it occurs for all rows in the library on every keystroke in the search bar.\n**Action:** Use a `WeakMap` with the object reference of the row as the key to cache the generated search string to avoid recomputing it repeatedly.
